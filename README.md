# xfhide

隐藏联系人

只支持 **微信 8.0.76**，装在 root + LSPosed 的手机上。

> ⚠️ **微信版本是硬性的。** 隐藏靠匹配微信内部的类名和方法，升级微信用的一整套锚点就会全变。8.0.76 以外装上去不会崩，但功能不会生效——所以请在升级微信前先确认有新版本模块可用。

---

## 打开设置页

| 方式     | 操作                                |
| ------ | --------------------------------- |
| 模块 App | 打开 xfhide → 点「打开微信里的密友设置」         |
| 聊天框指令  | 在**任意聊天**的输入框输入 `#set`，不用发送，输完就弹出 |
| 微信设置   | 我 → 设置 → 关怀模式 → **长按「开启」**        |

第三种是隐藏入口，不给外人看见，也没有开关能关掉它。

## 隐藏位置

| 分组          | 开关                                                    |
| ----------- | ----------------------------------------------------- |
| **会话与消息**   | 会话列表 · 未读角标 · 自动免打扰 · 消息通知 · 会话列表标题栏红点 · 微信团队提醒 · 拍一拍 |
| **通讯录与搜索**  | 通讯录 · 通讯录标签 · 新的朋友 · 群成员列表 · 全局搜索                     |
| **朋友圈与视频号** | 朋友圈消息 · 朋友圈互动 · 朋友圈动态 · 朋友圈分组图标 · 发现页红点 · 视频号点赞       |
| **通话**      | 音视频通话 · 自动拒绝音视频通话                                     |
| **访问控制**    | 禁止进入聊天 · 禁止查看资料 · 资料模拟非好友 · 拦截提交加好友 · 隐藏资料页朋友圈入口      |
| **其他入口**    | 收藏 · 微信运动 · 最近转发 · 存储空间管理 · 状态                        |

**通话是两个开关配合**：只开「音视频通话」，本机不响不显示，对方仍会响到 60 秒超时；再打开它下面的「自动拒绝音视频通话」，模块代你拒接，对方看到「已拒绝」。

### 四个有代价的开关

- **未读角标** — 靠把会话标成已读实现。已经清掉的未读，事后**无法还原**。想保留"收到过消息"的痕迹就别开。
- **自动免打扰** — 加入名单时立刻开免打扰；把人从名单里去掉**不会**恢复他原来的免打扰设置。
- **通讯录标签** — 标签成员在存储层过滤。代价是按标签群发时，隐藏联系人也**收不到**。
- **消息通知** — 隐藏状态下不弹通知、不显示横幅。想保留提醒感，可以另开「微信团队提醒」，新消息会变成一条来自「微信团队」的提示。

## 临时显示与恢复隐藏

| 指令      | 作用                      |
| ------- | ----------------------- |
| `#show` | 临时显示。名单里的人回到会话列表，可以正常聊天 |
| `#hide` | 恢复隐藏，刚才放出来的痕迹重新消失       |

在**任意聊天的输入框**输入即可，不用发送，输完立刻生效（输入框会被清空，不会留下记录）。

指令可以改：**更多** → 「指令」，改成你自己记得住的字串。改名后旧指令立即失效。

页面会提示当前状态，例如「已恢复隐藏，输入 #show 可重新显示」。

## 定时

**更多** → 「定时」→ 「新增时段」。

- 填 `HH:mm`
- 选动作：**到点隐藏** 或 **到点恢复显示**
- 选频率：**每天** 或 **一次**
- 「确定」保存

时段可以随时删除。恢复显示会一直保持到下一次「到点隐藏」，不会自己弹回去。

> 提示：如果手机在设定时间处于深度休眠，触发可能推迟到微信下次活跃时。想让定时准时，请把微信在系统省电设置里设为「不限制」。
